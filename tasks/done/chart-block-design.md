# Обновление дизайна блока графика сделок

Статус: готова к реализации

## Контекст и цель

Изменить подписи, расположение элементов и масштаб оси Y в существующем графике.
Интерфейс остаётся на армянском языке. Подготовка этого ТЗ не включает реализацию.

Проверено по исходникам:

- `src/ui/App.vue` содержит SVG-график с режимами `rooms` и `months`, локальные
  фильтры, кнопку обновления, подписи периода и модальное окно проблем.
- Сейчас полная сумма и количество сделок выводятся в отдельном `role="tooltip"`
  при наведении, фокусе, нажатии, Enter/Space; Escape закрывает подсказку.
- Верхняя граница Y равна максимальной сумме категории; четыре интервала делят
  диапазон от нуля до максимума на равные части. Для нулевых данных максимум — 1.
- Нижняя правая подпись `Արժույթ՝ AMD` видна только без проблемных сделок;
  при их наличии это место занимает кнопка `Խնդրահարույց գործարքներ`.
- Подпись периода содержит `Ամբողջ ժամանակահատվածը` в комнатном режиме без
  диапазона дат, год в месячном режиме и применённые границы фильтра дат.
- `/api/report` возвращает `year`, `rooms`, `months`, `problems`, `deals`;
  времени обновления в контракте нет. Сервер определяет год по `Asia/Yerevan`
  на момент начала загрузки (`src/report/load.cjs`, `src/report/aggregate.cjs`).
- Суммы приходят точными десятичными строками; полное форматирование сохраняет
  дробную часть. Сокращённые деления Y используют `հազ.`, `մլն`, `մլրդ`.
- График и панель фильтров независимо прокручиваются горизонтально на узком экране.

Источники: [описание отчёта](../docs/report.md),
[правила тестирования](../docs/testing.md), [App.vue](../src/ui/App.vue),
[существующие e2e](../tests/e2e/report.test.js).
Браузерная проверка текущего вида в ходе подготовки пока не выполнялась.

## Объём задачи

Изменить существующий блок графика в обоих режимах, включая управляющие элементы
и нижнюю информацию. Сохранить армянский интерфейс, фильтры, правила допуска квартир,
точные суммы, годовое ограничение месячного режима, список проблем и ручную загрузку.
Новых режимов, фильтров, зависимостей, хранения данных и изменений API не требуется.

## Требования

1. Убрать всплывающий блок данных. Сумму размещать над столбцом, количество
   сделок — под столбцом, ниже цифры комнатности или названия месяца.
   Подписи постоянно видны у всех столбцов в обоих режимах, без взаимодействия.
   Сумма полная, со знаком драма `֏`, без сокращений тысяч/миллионов/миллиардов.
   Разряды разделять пробелами; дробную часть сохранять как сейчас, с точкой,
   без округления: например, `1 234 567 890.123456 ֏`. Количество — только число.
   Для нулевой категории показывать `0 ֏` сверху и `0` под её названием.
   Название категории и обе подписи выровнять по центру столбца. Оставить место
   над самым высоким столбцом, чтобы сумма не обрезалась и не пересекала заголовок.
   Старую подсказку и зарезервированную под неё пустую область убрать.
2. Внизу слева показывать `Թարմացվել է՝` с датой и временем последнего
   успешного получения данных: `DD.MM.YYYY HH:mm:ss`, часовой пояс `Asia/Yerevan`.
   Фильтры и смена режима время не меняют. При загрузке и ошибке нижняя информация
   скрыта вместе с данными. Рядом показывать `Գործարքների քանակ՝ N`, где N —
   сумма количеств текущего графика после фильтров и ограничения годом в месячном
   режиме; проблемные сделки не входят в счётчик.
3. Убрать `Արժույթ՝ AMD`; внизу справа разместить описание X:
   `Սենյակների քանակ / Գործարքների քանակ / x` для комнат и
   `Կնքման ամսաթիվ / Գործարքների քանակ / x` для месяцев.
   Убрать центральное название X под столбцами.
4. Заменить заголовок `Ընդհանուր արժեք (AMD)` на
   `y / Ընդհանուր արժեք (֏)`. Буквы `x`, `y` и разделители `/` в подписях
   отображаются буквально, это не обозначения вариантов текста.
5. Полностью убрать подпись периода: `Ամբողջ ժամանակահատվածը`, отдельный год
   месячного режима и строку применённого диапазона дат. Поля фильтра дат сохраняются.
   Месячный режим по-прежнему рассчитывается по году из снимка API.
   Перенести кнопку обновления на место прежней подписи периода, справа от
   заголовка Y, ниже переключателей режима, вне прокручиваемой области SVG.
6. У кнопки обновления оставить иконку без видимого `Թարմացնել`, сделать её
   квадратной. Сохранить доступное имя кнопки и возможность повторить загрузку
   после ошибки; при текущем запросе кнопка должна оставаться заблокированной.
   Использовать существующую иконку обновления; доступное имя — `Թարմացնել`.
   Кнопка присутствует также при первой загрузке, ошибке и пустых данных,
   хотя сами данные и нижняя информация во время загрузки/ошибки скрыты.
7. Над парой переключателей `Սենյակների քանակ` и `Կնքման ամսաթիվ`
   по центру разместить `Ցուցադրություն`.
8. Округлять максимальную сумму вверх для верхнего деления Y и делить полученный
   диапазон на четыре равных интервала. Пример: максимум около 7,5 млрд →
   верхняя граница 8 млрд → ненулевые деления 8 / 6 / 4 / 2 млрд.
   Округление вверх до старшего десятичного разряда: 750 млн → 800 млн.
   Подробное правило и примеры приведены ниже.
9. Нижняя компоновка на широком экране: слева две строки — время обновления и
   общий счётчик; справа подпись X. Кнопка `Խնդրահարույց գործարքներ` при наличии
   проблем располагается отдельной строкой ниже справа. Подпись X не скрывается
   при наличии этой кнопки. Модальное окно и общий список проблем сохраняются.
10. На узком экране нижние элементы идут сверху вниз: информация слева,
    затем подпись X с выравниванием вправо, затем кнопка проблем справа.
    Длинный текст может переноситься, без наложений и прокрутки всей страницы.
    Полные суммы над столбцами не сокращать и не обрезать: увеличить необходимую
    ширину места под категории, сохранив горизонтальную прокрутку графика.
    Панель фильтров прокручивается независимо. Заголовок `Ցուցադրություն`
    и переключатели остаются по центру блока, внешние подписи и обновление
    не перемещаются при прокрутке графика.

### Правило шкалы Y

Пусть M — наибольшая сумма категории **текущего** графика после фильтров.
При M > 0 определить старший десятичный разряд p (степень десяти, для которой
p ≤ M < 10p), затем верхнюю границу U = ceil(M / p) × p. Если M уже кратно p,
не увеличивать его. Шаг — U / 4. На оси пять отметок: 0, U/4, U/2, 3U/4, U.
Геометрию столбцов рассчитывать относительно U; сами суммы не округляются.
При M = 0 или отсутствии категорий для расчёта использовать U = 1.
При отсутствии категорий комнатного режима сохраняется существующее пустое
состояние без столбцов; правило не требует создавать фиктивные категории.

| Максимум M | Верхняя граница U | Шаг |
| --- | --- | --- |
| 7 500 000 000 | 8 000 000 000 | 2 000 000 000 |
| 8 000 000 000 | 8 000 000 000 | 2 000 000 000 |
| 8 000 000 001 | 9 000 000 000 | 2 250 000 000 |
| 750 000 000 | 800 000 000 | 200 000 000 |
| 7 500 000 | 8 000 000 | 2 000 000 |
| 999 | 1 000 | 250 |
| 35.2 | 40 | 10 |
| 0.31 | 0.4 | 0.1 |
| 0.3 | 0.3 | 0.075 |
| 0 / пустой набор | 1 | 0.25 |

Деления сохраняют армянское форматирование и сокращения `հազ.`, `մլն`, `մլրդ`.
Предотвратить артефакты двоичной арифметики на точных границах и в подписях;
не выводить, например, `0.30000000000000004`. Шкала пересчитывается при смене
режима, фильтров и успешном обновлении.

### Данные, состояния и доступность

Время фиксируется на клиенте после успешного получения и принятия полного снимка,
включая успешный пустой ответ. Это время обновления данных страницы, а не изменения
сделок в CRM или локального пересчёта. При ошибке новое время не фиксировать.
После успешного пустого ответа показывать новое время и счётчик 0.

N = сумма `count` всех категорий текущего режима, включая категории за пределами
видимой из-за прокрутки части графика. На пустом результате N = 0. Для месячного
режима учитывать только год снимка; для комнат — все подходящие даты.

Сохранить сообщения загрузки, ошибки и `Տվյալներ չկան`, правила блокировки
фильтров, сохранение режима/фильтров при обновлении, 12 категорий месяцев и
выбранные комнатные категории с нулевыми значениями. Не выполнять новых запросов
при переключении и фильтрации. Окно проблем по-прежнему закрывается при обновлении.

Данные каждой категории должны оставаться доступны вспомогательным технологиям
вместе с категорией, суммой и количеством. Получение значений не требует hover,
клика или клавиатурного действия; эти действия не открывают tooltip. Сохранить
управление кнопками с клавиатуры, видимый фокус и доступность модального окна.

## Критерии приёмки

- **К1.** В обоих режимах все категории постоянно показывают полную сумму с `֏`
  над столбцом и число сделок под названием, включая нулевые категории. Tooltip
  отсутствует при любом прежнем способе его открытия; точность суммы сохранена.
- **К2.** Заголовки X/Y и `Ցուցադրություն` соответствуют точным строкам требований.
  Центральной подписи X, `Արժույթ՝ AMD` и всей отдельной подписи периода нет,
  в том числе при применённом фильтре дат и в месячном режиме.
- **К3.** Квадратная кнопка с одной иконкой и доступным именем `Թարմացնել`
  находится справа от Y, запускает обновление, блокируется на время запроса
  и позволяет повторить его после ошибки.
- **К4.** Нижний счётчик равен числу сделок текущего графика после режима/фильтров,
  не включает проблемные сделки, меняется без дополнительного запроса.
- **К5.** Время соответствует последней успешной загрузке, отображается с секундами
  по Еревану и не меняется от переключения режима/фильтров. Загрузка и ошибка
  скрывают данные и нижнюю информацию; успешный пустой ответ показывает время и 0.
- **К6.** Масштаб Y соответствует формуле и таблице, имеет четыре равных интервала
  с нулём и пересчитывается по текущим категориям. Столбцы не выходят за U.
- **К7.** Нижняя компоновка соответствует широкому и узкому вариантам;
  кнопка проблем и подпись X видны одновременно. Список проблем, ссылки,
  закрытие окна и возврат фокуса сохраняют прежнее поведение.
- **К8.** На ширинах 1440 и 375 px длинные суммы и названия не перекрываются
  и доступны полностью через прокрутку графика; страница не прокручивается
  горизонтально, внешние элементы неподвижны относительно блока графика.
- **К9.** Правила выборки, фильтрации, текущего года, пустых категорий и точной
  агрегации сохранены; полный набор unit/API/e2e проходит без регрессий.

## План реализации

1. Изменить разметку и состояние в `src/ui/App.vue`, стили при необходимости
   в `src/ui/style.css`: удалить состояние/обработчики старого tooltip и вычисление
   `period`, перенести обновление, добавить подписи и нижнюю информацию.
   Ширину SVG и интервалы категорий согласовать с полными подписями; выделить
   верхний отступ для максимальной суммы. Не добавлять библиотеку графиков.
2. Выделить правило масштаба в импортируемую функцию приложения для unit-тестов.
   Конкретный файл выбрать при реализации в соответствии со структурой проекта.
3. Фиксировать на клиенте время успешного получения и принятия снимка данных,
   форматировать по `Asia/Yerevan`. Счётчик вычислять по текущим `categories`.
   Новое поле API для этого поведения не требуется.
4. Обновить существующие e2e вместо удаления проверок точных сумм, количества,
   доступности, фильтров, обновления и адаптивности вместе со старой подсказкой.
   Добавить unit-проверки масштаба и других выделенных правил. Удалить только
   утратившие актуальность ожидания tooltip, отдельного года/периода и старого
   расположения обновления; покрытие бизнес-правил сохранить. При необходимости
   обновить локаторы графика с учётом его доступной семантики.
5. Выполнить обязательный полный `npm test`, исправить регрессии.
6. После реализации и успешных проверок запустить `docs-maintainer` по
   [правилам проекта](../docs/documentation.md), дождаться результата,
   проверить изменения `docs/` и ссылки корневого навигатора до сдачи.
   Подготовка самой постановки этого этапа не запускает.

7. **Пустые данные (К1, К4, К5, К6, К9, e2e).** Успешно загрузить пустой набор

## Проверка результата

Команды подтверждены `package.json` и `docs/testing.md`:

```sh
npm run test:unit
npm run test:e2e -- --runTestsByPath tests/e2e/report.test.js
npm test
```

E2e автоматически собирает production-версию и запускает сервер. При отсутствии
Chromium используется `npm run test:install`. Результат не считается успешно
сданным при незавершённых обязательных проверках; исполнитель сообщает сбои
и ограничения. Во время подготовки ТЗ тесты не запускаются: функционал не меняется.

## Согласованные решения

Первый раунд: пользователь подтвердил постоянные подписи всех столбцов
в обоих режимах, полную сумму со знаком драма и буквальные тексты X/Y,
указанные в требованиях 3–4.

Второй раунд: пользователь выбрал счётчик текущего графика, предложенную
семантику времени успешной загрузки и округление Y до старшего разряда.

Третий раунд: пользователь выбрал полное удаление подписи периода, включая год
и диапазон дат, и подтвердил нижнюю компоновку для широкого/узкого экрана,
числовые подписи количества, нулевые значения, расширение места для полных сумм,
примеры округления, сохранение точной границы, отметку нуля и шкалу 0–1.

Открытых продуктовых вопросов нет. Подготовка задачи не разрешает автоматически
начинать реализацию или публикацию.
