# Отчёт по сделкам

## Интерфейс

Страница на армянском языке показывает один SVG-график. Начальный режим —
`Սենյակների քանակ` (комнатность за всё время), второй — `Կնքման ամսաթիվ`
(месяцы текущего года). Переключение использует уже загруженный снимок,
не вызывает CRM и не меняет общий список проблем.

При открытии и нажатии `Թարմացնել` сервер заново читает всю выборку.
Таймера обновления нет. На время запроса прежние данные скрываются, кнопка
блокируется, подсказка и окно проблем закрываются; выбранный режим сохраняется.
Загрузка, ошибка и отсутствие данных имеют разные сообщения. После ошибки
можно повторить обновление; частичный результат не показывается.

Ось Y показывает AMD с армянскими сокращениями тысяч, миллионов и миллиардов.
Наведение, нажатие или фокус на столбце открывают полную сумму без сокращения
и количество учтённых сделок; Enter/Space также открывают подсказку, Escape закрывает.
График прокручивается горизонтально независимо от страницы на узком экране.

Кнопка `Խնդրահարույց գործարքներ` видна только при наличии проблем и показывает
количество уникальных сделок. Модальное окно содержит ID со ссылкой на CRM
и причины, без исходных значений полей. Список прокручивается внутри окна.
Закрытие доступно крестиком, Escape и нажатием на фон; фокус удерживается внутри
и возвращается на кнопку. Ссылки открываются в новой вкладке с
`rel="noopener noreferrer"`.

## Выборка и расчёт

Используется полная доступная владельцу вебхука выборка воронки **Վաճառք**,
стадии **Կնքված**, без фильтра по датам. Метаданные и все страницы читаются
существующим [клиентом Битрикс24](bitrix24.md). Отказ любой страницы отменяет
весь отчёт. Площадь читается общей интеграцией, но в расчёте не участвует.

| Поле | Допустимое значение | Последствие ошибки |
| --- | --- | --- |
| `Սենյակների քանակ` | Положительное безопасное целое число; допускается числовая строка | Исключение только из комнатного графика |
| `Կնքման ամսաթիվ` | Реальная календарная дата `YYYY-MM-DD` либо ISO datetime с часовым поясом | Исключение только из месячного графика |
| `opportunity` | Конечное положительное число или десятичная числовая строка, в том числе экспоненциальная запись | Исключение из обоих графиков |
| `currencyId` | Точно `AMD` | Исключение из обоих графиков; конвертации нет |

Пустые значения, boolean, массивы и объекты не становятся числами.
Нулевая и отрицательная суммы недопустимы; дробная комнатность недопустима.
Неверная дата не переносится автоматически на следующий месяц. У datetime
используется исходная календарная часть без пересчёта часового пояса.
Год отчёта определяется по `Asia/Yerevan` на момент начала загрузки;
прошлые и будущие годы сами по себе не являются проблемой.

Комнатная ось включает все целые категории от 1 до максимальной допустимой
комнатности во всей выборке, даже если сделка с максимумом исключена по сумме
или валюте. Пропуски получают сумму `0` и количество `0`. Если допустимой
комнатности нет, массив пуст. Месячная ось всегда содержит 12 месяцев;
учитываются только даты года отчёта. Количество отражает сделки, реально
включённые в конкретный столбец.

Агрегация складывает десятичные коэффициенты `BigInt` с общей точностью.
API передаёт суммы строками без двоичной ошибки сложения (`0.1 + 0.2` даёт `0.3`).
Это сохраняет точность полученных значений, но не восстанавливает разряды,
которые CRM уже потеряла при передаче JSON-числа. Геометрия SVG и сокращённые
деления оси используют `Number`; полная подсказка форматирует строку суммы.

Проблемы собираются за всё время независимо от режима: одна строка на ID,
все причины, сортировка по числовому ID. Сделка может быть проблемной и при этом
учитываться в одном из графиков, если второе поле группировки корректно.

## HTTP-контракт

`GET /api/report` возвращает JSON UTF-8 с `Cache-Control: no-store`.
Параметров фильтрации нет. Успешный ответ имеет статус 200:

```text
{
  year: number,
  rooms: [{ category: number, amount: string, count: number }],
  months: [{ category: number, amount: string, count: number }],
  problems: [{ id: number, url: string, reasons: [{ field: string, code: string }] }]
}
```

`months.category` — 1–12. `reasons.field` — `rooms`, `date`, `amount`, `currency`;
`code` — `missing`, `invalid` или `unsupported_currency` (для иной строковой валюты).
Пустая выборка даёт `rooms: []`, 12 нулевых месяцев и `problems: []`.

Ссылка строится из HTTPS origin портала и проверенного положительного целого ID:
`/crm/deal/details/<ID>/`. Путь вебхука и токен в ответ не входят. Некорректный ID
отклоняет весь снимок. В API нет сырых сделок и внешних сообщений об ошибках.

| Статус | Тело | Значение |
| --- | --- | --- |
| 500 | `{"error":"CONFIGURATION_ERROR"}` | Настройка отсутствует или некорректна; CRM не вызывается |
| 502 | `{"error":"CRM_READ_ERROR"}` | Ошибка чтения CRM, метаданных, страниц или обработки снимка |

[`load.cjs`](../src/report/load.cjs) связывает настройку, клиент и агрегацию;
[`aggregate.cjs`](../src/report/aggregate.cjs) содержит чистые расчёты;
[`App.vue`](../src/ui/App.vue) — UI и локальное состояние.
Запуск — в [паспорте](project.md), покрытие сценариев — в [testing.md](testing.md).
